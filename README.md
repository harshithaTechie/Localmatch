# LocalMatch — Hyper-Local Freelance Marketplace

LocalMatch is an AI-powered, hyper-local marketing marketplace that connects neighborhood small businesses with local freelance content creators for quick-turnaround marketing tasks (Instagram Reels, TikTok promos, food photography, local SEO).

## 🚀 Key Features
- **AI-Powered Project Scoping:** Translates informal business owner requests into structured deliverables and skill tags using Google Gemini AI.
- **Open Freelancer Marketplace:** Filter local gigs by category, skill set, and neighborhood.
- **1-Click Application & Demo Profiles:** Instant demo access for business owners and creators to streamline review and testing.
- **Proposal & Application Tracking:** Real-time application tracking with Supabase.

## 🛠 Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express.js
- **Database & Auth:** Supabase (PostgreSQL)
- **AI Scoping Engine:** Google Gemini API
